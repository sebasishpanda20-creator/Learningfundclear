Methodology

LearningFundClear is a small dataset and a few formulas. This page documents both, so the site can be audited rather than trusted.

AMFI publishes this file every working day, free of charge. LearningFundClear uses nothing else: no NSE or BSE feeds, no scraped websites, no broker APIs, no third-party quote providers.

What is excluded, and why

  • Closed-ended and interval schemesNot open for purchase
  • Rows with stale NAVsDropped, not shown as current
  • Rows with a blank plan column5,760 rows; ambiguous, so dropped
  • IDCW-only rowsGrowth option kept, for comparability
  • Most fund housesCapped, to keep the file small
  • Exchange-traded pricesLicensed data, deliberately absent

The raw file holds roughly 18,000 rows, most of which are duplicate plans, closed schemes or dead entries. The curation step is deliberately conservative about freshness: a scheme whose NAV is more than two days behind the newest date in the file is dropped, because showing a stale NAV as today's price would be worse than omitting the scheme.

On the blank plan column. AMFI leaves this column empty on about 5,760 rows — ETF series, legacy plans and segregated portfolios. Those rows carry a real scheme name and a real NAV, but nothing that says which plan they are. Because the site's central comparison is Direct versus Regular, a guessed label there would have been worse than a missing row: it would have invented plan identity and could have manufactured pairs that the publisher never published. So those rows are excluded, and only the 8,634 rows carrying an explicit Direct Plan or Regular Plan are eligible.

Why expense ratios are assumptions, not data

Expense ratio (TER) is the single most useful number for the Direct-versus-Regular comparison, and it is the one number AMFI does not publish in a machine-readable file. LearningFundClear checked: the TERAll.txt path that older tools referenced now returns HTTP 404, and the public pages expose no equivalent file.

So the site does the honest thing rather than the convenient one. Each category carries an illustrative industry range for direct and regular plans, it is labelled as an assumption wherever it appears, and every calculator that uses it lets you overwrite it with the figure from the fund's own factsheet. No page on this site claims a per-scheme expense ratio.

Before you rely on any rupee figure involving a fee, take the real expense ratio from the fund's factsheet or the AMC's website, type it into the calculator, and see whether the conclusion still holds. Often it does; sometimes it does not.

How the data is verified

Faithfulness is checkable, so this site checks it instead of asking you to trust it. One script downloads AMFI's file again and looks up every scheme published here by its scheme code, comparing the name, NAV, NAV date, plan and option against the publisher's own row. It fails loudly if anything differs. 

python tools/verify-data.py

The run behind this build: 1,401 schemes checked, 0 discrepancies — every NAV and date matched AMFI's file exactly, and every plan label came from AMFI's own plan column. That result is not cached anywhere on the site — run the command to get today's numbers.

One honest exception, stated because it is the kind of thing these pages usually hide: scheme names here have runs of whitespace collapsed to a single space, because AMFI's file contains a few double spaces. No word is added, removed or reordered.

The formulas, exactly

These are the only calculations on the site. You can reproduce every number by hand.

SIP, compounded monthly, instalment added at the start of each month
  i = assumed annual return / 12 / 100
  balance = 0, invested = 0, instalment = monthly amount
  for month = 1 .. years*12:
      if month > 1 and (month - 1) % 12 == 0 and step-up > 0:
          instalment = instalment * (1 + step-up / 100)
      balance  = (balance + instalment) * (1 + i)
      invested = invested + instalment

Lumpsum
  value = amount * (1 + assumed annual return / 100) ^ years

Expense-ratio drag
  direct  = SIP with rate = (gross return - direct expense ratio)
  regular = SIP with rate = (gross return - regular expense ratio)
  cost of the higher TER = direct value - regular value

Excluded from all three: exit loads, stamp duty, capital gains tax, and any drift in expense ratio over time. Returns are assumed to arrive smoothly, which real markets never do.

Refreshing the data

The site is a static build with no server. The dataset is regenerated by one script and committed. 

python tools/refresh-data.py         # downloads AMFI's file, rewrites assets/js/data.js
python tools/refresh-data.py --check # reports what changed, writes nothing
python tools/verify-data.py          # checks the result against AMFI's file, field by field

Nothing else needs rebuilding: every page reads the same file at load time, so a refresh is also a deploy. The included GitHub Actions workflow does this nightly and publishes the result.

Known limitations

  • No history or charts. The build stores one NAV per scheme, so there is no performance graph. Adding one means storing a time series, which is a much larger file.
  • No riskometer or portfolio data. Those live in scheme documents, not in the NAV file.
  • Pages render in the browser. The data file is loaded by JavaScript, which is simple and free but weaker for search engines than pre-rendered pages. Generating a static page per scheme is the obvious next improvement.
  • Names are AMFI's. Fund names appear as published, including their own inconsistent casing and spelling (all-caps for some fund houses, mixed case for others). The only transformation is that runs of whitespace are collapsed to one space, because a few names carry double spaces.
  • A snapshot is a snapshot. NAVs move daily; the date stamped on every page is the date of the data, not of your visit.

What LearningFundClear does not do

  • No buy, sell or hold calls on any scheme or security — LearningFundClear is not registered as a research analyst or investment adviser, and does not give advice.
  • No expected, assured or projected returns. Ever.
  • No ranking of funds by "best", no model portfolios, no tips, no subscription signals.
  • No exchange price data, stock screener or IPO grey-market premium.
  • No accounts, cookies, analytics or advertising.
  • No distributor relationship and no commission, so the Direct-versus-Regular comparison is not conflicted.

If you want a recommendation about what to buy for your situation, that is a job for a SEBI-registered investment adviser who can look at your goals, taxes and existing holdings.
